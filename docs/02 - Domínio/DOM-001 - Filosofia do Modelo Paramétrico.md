# Filosofia do Modelo Paramétrico

**Projeto:** Esboce

**Versão:** 1.0

**Status:** Canônico

---

# Objetivo

Definir a filosofia que orienta o comportamento interno da residência digital no Esboce.

Este documento estabelece como uma casa deve ser compreendida pelo sistema e serve como referência para toda implementação do modelo paramétrico.

---

# O Problema dos Softwares Tradicionais

A maioria dos softwares de desenho representa uma residência como um conjunto de geometrias independentes.

Paredes.

Linhas.

Faces.

Volumes.

Cada elemento existe quase de forma isolada.

Quando um componente é alterado, os demais precisam ser ajustados manualmente ou através de regras específicas.

A construção é tratada como um desenho.

---

# A Filosofia do Esboce

No Esboce, uma casa não é um desenho.

Ela é um organismo digital.

Cada componente conhece seu papel dentro da residência.

Cada alteração produz consequências naturais em todo o sistema.

O usuário modifica apenas uma parte.

O sistema compreende o impacto sobre o todo.

---

# O Organismo Digital

Uma residência é composta por diversos organismos menores.

Casa

↓

Ambientes

↓

Elementos Construtivos

↓

Componentes

↓

Produtos

Cada nível possui consciência do contexto em que está inserido.

---

# Consciência Sistêmica

Nenhum elemento existe isoladamente.

Uma parede conhece:

- os ambientes que separa;
- as paredes conectadas;
- as portas existentes;
- as janelas existentes;
- a cobertura apoiada;
- a fundação correspondente;
- os materiais utilizados;
- os quantitativos gerados.

Ela não é apenas uma geometria.

Ela é uma entidade inteligente.

---

# Relações Inteligentes

Quando uma parede é movimentada:

o ambiente é atualizado;

a área útil é recalculada;

o piso acompanha;

o forro acompanha;

a cobertura entende a alteração;

as esquadrias permanecem coerentes;

os quantitativos são atualizados;

o orçamento é recalculado;

os indicadores de desempenho são revisados.

O usuário executou apenas uma ação.

A residência inteira respondeu.

---

# Propagação Natural

Toda alteração deve se propagar de forma consistente.

As consequências não são comandos independentes.

São comportamentos naturais do modelo.

A casa reage.

Não apenas muda.

---

# Integridade Inviolável

Toda operação realizada no Esboce deve preservar a consistência do modelo de domínio.

Nenhuma ação válida pode deixar a residência em um estado inconsistente.

Após qualquer alteração, a casa continua sendo uma residência íntegra, com todas as relações entre seus elementos preservadas.

Quando uma operação colocar essa integridade em risco, o sistema deverá adotar uma das seguintes estratégias:

- impedir a operação antes que ela seja concluída;
- ajustar automaticamente os elementos relacionados para manter a consistência;
- informar claramente ao usuário por que a operação não pode ser realizada.

A integridade do modelo nunca pode depender da intervenção manual do usuário.

---

## A Confiança do Usuário

O usuário deve sentir liberdade para experimentar.

Mover paredes.

Redimensionar ambientes.

Trocar coberturas.

Adicionar componentes.

Remover elementos.

Durante todo esse processo, ele deve confiar que o Esboce preservará automaticamente a coerência da residência.

O sistema assume a responsabilidade pela integridade do projeto.

O usuário permanece focado apenas na criação.

---

## Exemplos

Mover uma parede não pode deixar um ambiente aberto.

Remover uma parede estrutural não pode produzir uma cobertura sem apoio.

Eliminar uma janela deve atualizar automaticamente quantitativos, orçamento e desempenho.

Excluir um ambiente deve atualizar todas as relações dependentes.

Em qualquer situação, a residência permanece válida segundo as regras do domínio.

---

## Princípio

A liberdade criativa nunca pode comprometer a integridade da residência.

O Esboce protege o modelo para que o usuário possa criar sem medo.

# O Papel da Parametrização

Parâmetros não existem apenas para modificar dimensões.

Eles representam conhecimento.

Largura.

Altura.

Espessura.

Material.

Desempenho.

Custo.

Vida útil.

Relacionamentos.

Cada parâmetro participa do comportamento da residência.

---

# Inteligência Emergente

A inteligência do Esboce não depende exclusivamente de Inteligência Artificial.

Ela nasce da qualidade das relações existentes entre os elementos.

Quanto melhor o modelo de domínio, mais inteligente será a residência.

---

# Princípios

Uma casa nunca é um conjunto de linhas.

Uma alteração nunca afeta apenas um objeto.

Todo elemento conhece seu contexto.

Toda informação possui significado.

Toda mudança gera consequências coerentes.

O sistema assume a complexidade.

O usuário permanece focado apenas na criação.

---

# Declaração

O objetivo do Esboce não é desenhar residências.

É representar digitalmente uma residência com o mesmo comportamento lógico que ela possui no mundo real.

Quando uma parede muda, não apenas sua geometria é alterada.

A casa inteira compreende essa mudança.

É essa consciência sistêmica que transforma um desenho em um organismo digital vivo.

---

> "Enquanto a maioria dos softwares desenha edifícios, o Esboce compreende edifícios."
