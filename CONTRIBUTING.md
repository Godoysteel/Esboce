# Contribuindo com o Esboce

## Objetivo

O Esboce é desenvolvido seguindo princípios de engenharia orientados por documentação, arquitetura e evolução controlada.

## Princípios

Toda alteração relevante deve:

- respeitar a arquitetura definida;
- manter consistência com o modelo de domínio;
- atualizar documentação relacionada;
- registrar decisões importantes através de ADRs.

## Processo de Desenvolvimento

1. Criar uma branch de trabalho.
2. Implementar a alteração.
3. Atualizar documentação.
4. Revisar impacto arquitetural.
5. Realizar commit.
6. Integrar à branch principal.
